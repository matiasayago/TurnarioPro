# Knowledge Base

Base de conocimiento organizacional consultada por todos los agentes antes de proponer soluciones nuevas. Ver [`docs/10-memory-knowledge-platform.md`](../docs/10-memory-knowledge-platform.md).

- `estandares/` — estándares de desarrollo y convenciones de código.
- `plantillas/` — plantillas (historias de usuario, documento funcional, documento de arquitectura, etc.).
- `patrones-arquitectonicos/` — arquitecturas y patrones reutilizables.
- `frameworks-librerias-aprobadas/` — stack tecnológico aprobado por CTO IA.
- `manuales-internos/` — manuales internos de la empresa.

Gobernada por CTO IA (estándares y librerías) y alimentada por todos los agentes al cierre de cada proyecto.
