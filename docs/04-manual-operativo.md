# Documento 004
AI Software Factory
Manual Operativo v1.0
Autor: Matías SayagoFecha: Agosto 2026

## 1. Objetivo
Definir las normas operativas de la AI Software Factory para garantizar un proceso repetible, medible y de alta calidad.

## 2. Principios Operativos
- El CEO define la estrategia.- El Director General IA coordina.- Los agentes trabajan sobre una memoria compartida.- Toda decisión queda registrada.- Ningún cambio llega a producción sin aprobación.

## 3. Ciclo de Vida del Proyecto
Fase 1: Inicio• El CEO registra el proyecto.• Se asigna un identificador único.Fase 2: Descubrimiento• Business Analyst releva requisitos.• Product Manager construye backlog.Fase 3: Diseño• CTO valida tecnologías.• Arquitecto define arquitectura.• UX/UI diseña experiencia.Fase 4: Desarrollo• Backend, Frontend y Mobile implementan.• Integraciones desarrolla conectores.Fase 5: Calidad• QA ejecuta pruebas.• Security revisa vulnerabilidades.Fase 6: Despliegue• DevOps prepara CI/CD y publica.Fase 7: Cierre• Technical Writer genera documentación.• Director IA consolida resultados.• CEO aprueba la entrega.

## 4. Comunicación entre Agentes
Todas las interacciones pasan por el Director General IA. Cada agente publica el estado de sus tareas y registra decisiones en la memoria compartida.

## 5. Gestión del Conocimiento
La Base de Conocimiento almacena estándares, plantillas, arquitecturas reutilizables, decisiones técnicas y lecciones aprendidas.

## 6. Gestión de Riesgos
Cada agente puede registrar un riesgo. El Director IA lo clasifica por impacto y probabilidad y propone un plan de mitigación.

## 7. Gestión de Cambios
Todo cambio debe tener motivo, responsable, impacto estimado, aprobación y trazabilidad.

## 8. Gobierno Técnico
El CTO IA define estándares, bibliotecas aprobadas, convenciones de código y criterios de arquitectura.

## 9. Calidad
Se aplican revisiones de código, pruebas automatizadas, análisis estático y validaciones de seguridad antes de cada despliegue.

## 10. KPIs
• Tiempo de entrega• Defectos• Cobertura de pruebas• Tiempo medio de despliegue• Retrabajo• Satisfacción del cliente

## 11. Matriz RACI (Resumen)
CEO: Aprueba.Director IA: Responsable de coordinación.PM: Responsable del producto.CTO: Responsable técnico.Arquitecto: Responsable del diseño.Desarrollo: Responsable de implementación.QA: Responsable de validación.DevOps: Responsable del despliegue.

## 12. Roadmap Operativo
Versión 1: Orquestación.Versión 2: Automatización.Versión 3: Autoasignación inteligente.Versión 4: Optimización basada en métricas.

## Anexo - Flujo Resumido
CEO → Director IA → Business Analyst → Product Manager → CTO → Arquitecto → UX/UI → Desarrollo → QA → Security → DevOps → Technical Writer → Director IA → CEO
