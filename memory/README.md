# Memory

Memoria organizacional de la AI Software Factory. Ver [`docs/10-memory-knowledge-platform.md`](../docs/10-memory-knowledge-platform.md) §4.

- `proyectos/` — memoria de proyecto: decisiones, arquitectura y tareas de cada proyecto activo o cerrado (uno por subcarpeta, ver `proyectos/`).
- `organizacional/` — memoria organizacional: estándares, plantillas y lecciones aprendidas transversales a todos los proyectos.
- `sesiones/` — memoria de sesión/histórica: contexto puntual de conversaciones y ejecuciones relevantes.

Toda decisión relevante de cualquier agente debe quedar registrada aquí para que otros agentes puedan reutilizar el contexto autorizado (principio operativo, ver `docs/04-manual-operativo.md` §2).
