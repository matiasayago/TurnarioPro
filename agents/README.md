# Agents (catálogo extendido)

Carpeta reservada para artefactos del "Catálogo de Agentes IA" que excedan el formato de
subagente de Claude Code — fichas de skills declaradas, niveles de seniority,
especializaciones por tecnología (ver evolución futura en
[`docs/03-catalogo-agentes.md`](../docs/03-catalogo-agentes.md) y el "Skill Engine" en
[`docs/02-arquitectura-general.md`](../docs/02-arquitectura-general.md) §7).

La definición operativa actual de cada rol (la que Claude Code invoca) vive en
[`.claude/agents/`](../.claude/agents/).
